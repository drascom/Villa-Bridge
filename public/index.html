Connect Home Assistant to the same MQTT broker, then enable discovery when you are ready to publish the devices.

  1. In Home Assistant, open Settings → Devices & services → Add integration.
  2. Select MQTT and enter the broker address shown here.
  3. Use your Mosquitto username and password. Credentials are never displayed in this panel.
  4. Keep the discovery prefix as “homeassistant”, then enable discovery below.

Keep the tablet IP address stable

Current tablet IP: —. Your router may assign a different address after a restart.

  1. Recommended: create a DHCP reservation in your router. In the current Wi-Fi network details, find the MAC address Android uses for this network, then bind that MAC to the current IP.
  2. Alternative: Android Settings → Network & Internet → Internet → current network → pencil/advanced → IP settings → Static. Keep gateway, DNS and subnet values consistent with the router network.

This changes the tablet’s network address; it is different from editing the MQTT URL in Villa Bridge.
